# 🔐 الخزنة (SafeBox) — نسخة الويب

تطبيق ويبي **ثابت** (بدون خادم) لتشفير الملفات في المتصفح باستخدام
**AES-256-GCM** و **PBKDF2-HMAC-SHA256** عبر Web Crypto API.

> ✨ كل شيء يحدث داخل جهازك: لا يُرسل ملف أو كلمة مرور إلى أي خادم، ولا يحتاج الموقع لـ Backend.
> 📦 صيغة الملف مطابقة تماماً لنسخة Python، فما تشفّره هنا يُفتح بـ `cli.py` والعكس.

## 🌐 جربها الآن

👉 **https://lock2666.github.io/safebox/**

## ✨ المميزات

- 🔒 تشفير وفك تشفير أي ملف حتى 64 م.بايت
- 🔑 توليد مفاتيح عشوائية (256/384/512 بت) عبر `crypto.getRandomValues`
- 📝 تشفير النصوص إلى Base64 جاهز للنسخ
- 💪 مقياس قوة كلمة مرور لحظي + مولّد كلمات مرور
- 🔎 فحص ترويسة أي ملف مشفّر بدون كلمة مرور
- 🛡️ كشف تلقائي لأي تعديل على الملف (وسم GCM)
- 🕵️ خيار إخفاء اسم الملف الأصلي
- 📱 واجهة عربية RTL متجاوبة، تعمل على الجوال أيضاً

## 🚀 التشغيل محلياً

لأن Web Crypto يحتاج **سياقاً آمناً** (HTTPS أو localhost):

```bash
cd web
python -m http.server 8080
# ثم افتح: http://localhost:8080
```

أو افتح `index.html` مباشرة عبر امتداد Live Server في VS Code.

> ⚠️ فتح الملف بـ `file://` قد لا يعمل في بعض المتصفحات (بلا سياق آمن).

## 📐 صيغة الملف المشفّر

```
SBOX │VERSION│KDF│ITERATIONS│KEY_CHECK│SALT │NONCE│CIPHERTEXT + Tag
 4B  │  1B   │1B │   4B     │   4B    │ 16B │ 12B │   AES-256-GCM
```

| الحقل | الشرح |
|---|---|
| MAGIC | `SBOX` للتعرف على الصيغة |
| VERSION | إصدار الصيغة (1) |
| KDF | `0 = PBKDF2` (كلمة مرور) أو `1 = مفتاح مباشر` (ملف مفتاح) |
| ITERATIONS | عدد تكرارات PBKDF2 (100k / 600k / 1.2M) |
| KEY_CHECK | أول 4 بايت من SHA-256 للمفتاح (للتحقق السريع) |
| SALT / NONCE | قيم عشوائية فريدة لكل ملف |
| CIPHERTEXT | البيانات الوصفية (JSON) + بياناتك، مع وسم توثيق 16 بايت |

## 🔗 التوافق مع نسخة Python

```bash
# شفّر في المتصفح، وافتح بالسطر الأوامر:
python ../cli.py decrypt report.pdf.sbox -p "كلمة-المرور"

# أو شفّر محلياً وافتح في الموقع:
python ../cli.py encrypt report.pdf -p "كلمة-المرور"
```

## ⚠️ ملاحظات أمنية

1. اختر كلمة مرور 16 حرفاً على الأقل (المقياس يساعدك).
2. احفظ نسخة احتياطية من ملفاتك المهمة — لا استعادة ممكنة بدون المفتاح.
3. على الحاسوب المشترك، استخدم نافذة تصفح خاصة وأغلقها بعد الانتهاء.
4. الموقع لا يخفي حجم الملف؛ لتحقيق أعلى تخفٍ استخدم خيار «أخفي الاسم».
